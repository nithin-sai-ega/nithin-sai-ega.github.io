# Nithin Sai Ega — Portfolio

Source for [nithin-sai-ega.github.io](https://nithin-sai-ega.github.io), built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) template (MIT licensed, see [LICENSE](LICENSE)).

## Updating the site

- **About page:** `_pages/about.md` (add a photo by saving it as `assets/img/prof_pic.jpg` and uncommenting `image:`)
- **Projects:** `_projects/`
- **CV page:** `_data/cv.yml`
- **Downloadable resume:** replace `assets/pdf/Nithin_Sai_Ega_Resume.pdf` (keep the same filename)

## Run locally

```bash
docker compose up
```

Then open <http://localhost:8080/>.
